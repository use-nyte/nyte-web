# Nyte Web

Nyte Web is the web application for the Nyte media platform.

The application currently uses React and React Router, but is planned to transition to **SolidJS and TanStack Router**.

This section will document the frontend architecture, development environment, application features, and integrations.

[View source on GitHub](https://github.com/use-nyte/nyte-web).
